Mizar 是一个面向终端的 AI 编程工作台，专为重度命令行工作流打造。它同时提供全屏看板与保留终端滚动历史的 Inline 双模视口，并内置本地 Shell 直执行、跨层项目规则发现、MCP 服务接入与轻量 JS 编排沙箱。

无论你是想先体验交互界面，还是立刻接上 DeepSeek、OpenAI 或 Anthropic 开始改代码，一条命令即可进入工作状态。

## 启动后第一分钟做什么

进入工作台后，不必一次记住所有[快捷键](/tui/keybinds/)，先尝试这三件最立竿见影的事：

<Steps>
  <li>
    <p><strong>用 <code>@</code> 把关键源码精确喂给模型</strong>：在输入框输入 <code>@</code> 会弹出受 <code>.gitignore</code> 保护的文件补全列表。你甚至可以直接写 <code>@src/main.rs#L1-40 这段参数解析有哪些边界情况？</code>，省去大段复制粘贴。</p>
  </li>
  <li>
    <p><strong>用 <code>!</code> 和 <code>!!</code> 就在输入框里跑终端命令</strong>：以 <code>!!git status</code> 开头的命令纯属本地快速瞄一眼，不会写入对话上下文也不花一分钱 Token；换成单感叹号 <code>!cargo test</code>，命令报错会顺理成章成为下一轮对话背景，接着让 AI 帮你修即可。</p>
  </li>
  <li>
    <p><strong>用<a href="/tui/commands/">斜杠命令</a>与<a href="/tui/keybinds/">热键</a>掌控视图</strong>：按 <kbd>Ctrl</kbd>+<kbd>B</kbd> 打开右侧状态面板查看当前上下文占用与活跃文件；按 <kbd>F3</kbd> 在全屏专注模式与 Inline 滚动模式间无损切换；输入 <code>/model</code> 或 <code>/effort</code> 随时调整模型与推理深度。</p>
  </li>
</Steps>
