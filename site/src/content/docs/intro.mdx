Mizar 是基于自研 **Cordis 微内核（33 个 Cargo Crate：28 个运行时/插件 + 5 个纯核心）** 构建的 Rust 终端 AI 编程 Agent，唯一可执行入口为 `mizar`。系统围绕「流式推理 → 并行/串行工具执行 → 只追加 JSONL 会话持久化 → KV Cache 前缀稳定」主循环设计，同时提供交互式双模 TUI 工作台与确定性无头 `exec` 模式。

<Callout type="info" title="架构对齐说明">
  本手册对应当前 **33-Crate Cordis 微内核架构（v0.2.5）**：默认 `MinimalCoding` 4 核心工具、按需激活 QuickJS `codemode`、`<available_skills>` `<location>` 按需读取技能、精简静态英文系统提示词、启动期静态 `AGENTS.md` 加载、热缓存感知尾部剪枝与 `Compaction B-5` 护栏、宽容单会话 JSONL + SHA-256 Blob 持久化，以及 `--trace-out` 结构化轨迹导出。
</Callout>

## 安装

Mizar 固定基于 Rust `1.98.0`（Edition 2024）构建，可通过官方安装脚本获取预编译单二进制，或从源码构建与升级：

<CodeTabs
  tabs={[
    {
      label: '预编译安装',
      lang: 'sh',
      code: `curl -fsSL https://raw.githubusercontent.com/Mieluoxxx/Mizar/main/scripts/install.sh | sh
mizar --version`,
    },
    {
      label: '源码构建',
      lang: 'sh',
      code: `git clone https://github.com/Mieluoxxx/Mizar.git
cd Mizar
cargo install --locked --path crates/mizar-tui`,
    },
    {
      label: '自更新与搜索工具',
      lang: 'sh',
      code: `mizar update --check      # 仅检查最新版本
mizar update              # 升级至最新正式版
mizar update -v 0.2.5 -f  # 强制切换到指定版本
mizar install-tools       # 预装或校验托管 rg 与 fd`,
    },
  ]}
/>

如需隔离内网环境，可设置 `MIZAR_OFFLINE=1` 或 `MIZAR_SKIP_VERSION_CHECK=1` 跳过启动版本检查，或通过 `MIZAR_RELEASE_BASE_URL` 指向内部镜像仓库。

## 三分钟跑通首次会话

<Steps>
  <li>
    <strong>选择凭据方式（免 Key 演示或直连模型）</strong>：无 API Key 时可用内置离线 Mock 快速验证工具链；直连模型只需导出对应环境变量或配置 <code>~/.mizar/models.json</code>。
  </li>
  <li>
    <strong>启动终端或无头命令</strong>：不带提示词参数直接运行 <code>mizar</code> 进入交互式全屏工作台；传入 <code>exec</code> 或 <code>-p</code> 则运行单轮无头任务并打印最终结果。
  </li>
  <li>
    <strong>审计变更与性能轨迹</strong>：交互模式按 <code>Ctrl+T</code> 打开 <code>/trace</code> 三泳道剖面；无头模式传 <code>--trace-out trace.json</code> 导出结构化 <code>TrajectoryExport</code>。
  </li>
</Steps>

## 两种运行形态

| 运行入口 | 适用场景 | 交互能力 | 上下文与持久化 |
| :--- | :--- | :--- | :--- |
| `mizar [OPTIONS]` | 日常研发、多轮重构、代码审查 | Fullscreen / Inline 双视口、`!` / `!!` 本地命令、`--approve` 审批弹窗 | 默认按 `cwd` 分桶惰性写入 `~/.mizar/sessions/`（可用 `--no-persist` 关闭） |
| `mizar exec [OPTIONS] [<prompt>]` | CI 流水线、自动化评测、脚本批处理 | 无交互，支持纯文本或实时刷新的 NDJSON 事件流（`--json`） | 支持 `--isolated`、`--timeout`、`--context-window`、`--trace-out` 与标准退出码 |

<Callout type="tip" title="无显式路由时的报错行为">
  启动时若既未在环境变量与 <code>~/.mizar/models.json</code> 配置任何提供方，也未指定 <code>--provider mock</code>，Mizar 会返回明确的 <code>NoRouteConfigured</code> 错误，而不会静默发送空密钥请求。
</Callout>
