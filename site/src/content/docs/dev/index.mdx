Mizar 基于 **Rust 1.98.0**（edition 2024）构建，整个工作区收敛为 **10 个粗粒度 crate**，通过 **`mizar-core::spine::MizarRuntime` 静态组合根** 与 **`mizar-types::hooks` 强类型钩子 / `HookGuard`** 装配成「流式调模型 → 执行工具 → 回写会话」的主循环，以 **`mizar-tui`**（唯一二进制入口 `mizar`）交付终端工作台，并通过 **`mizar-client`** 供桌面端 Merak 直嵌复用。

仓库内的权威架构文档为 **`docs/plugins.md`** 与 **`AGENTS.md`**；架构与开发章节聚焦编译隔离红线、[静态装配与钩子实操](/dev/runtime/) 与 [工程规范](/dev/conventions/)。

## 编译隔离红线

1. **纯核 / 纯前端红线（2 个 Crate）**：以下 crate **严禁引入** `tokio`、`reqwest`、`rquickjs`、`rusqlite` 或 `tracing`：
   - `mizar-types`：纯核心契约、`hooks` 原语（`HookGuard` / `SyncEventBus` / `WaterfallHook` / `SerialHook`）、LLM 数据结构、轨迹计算与客户端纯算法（同时**严禁引入 `ratatui` / `crossterm` 及任何内部 crate**）；
   - `mizar-tui-ui`：纯终端渲染状态机、`TuiFeatures`、`pi-emphasis` 视觉语法与虚拟化 Markdown 渲染。
2. **Merak Desktop 直嵌红线**：**`mizar-client`（及 `mizar-types`）严禁引入 `ratatui`、`crossterm` 或 `mizar-tui-ui`**，确保跨端宿主运行时零终端依赖。

<Callout type="warning" title="编译能过，但架构红线不可突破">
  虽然 Cargo 技术上允许你在纯核心 crate 里加上 <code>tokio</code>，但一旦引入，异步或 I/O 副作用就会污染纯状态机与跨端数据模型，导致秒级单检与跨端复用失效。需要任何异步调度、HTTP 通信、JS 沙箱或落盘能力，必须上移到 <code>mizar-core</code> / <code>mizar-client</code> / <code>mizar-tui</code> 宿主层处理。
</Callout>

## 四层 10-Crate 拓扑概览

| 架构层级 | Crate 清单 | 职责边界 |
| :--- | :--- | :--- |
| **纯核心层（2）** | `mizar-types` · `mizar-tui-ui` | 零重运行时纯契约、`hooks`、轨迹算法与纯终端 UI 状态机，支持秒级 `cargo check` |
| **基础能力层（3）** | `mizar-llm` · `mizar-tools` · `mizar-session` | `LlmRuntime` + 三大协议适配器 + 路由重试；`ToolRuntime` 管线 + 6 工具 + `tool_search`；WAL SQLite 会话、`recall` 与 FTS5 |
| **隔离扩展层（2）** | `mizar-codemode` · `mizar-mcp` | 按 Cargo feature 可选装配的 `rquickjs` QuickJS JS 沙箱与外部 stdio/HTTP MCP 客户端 |
| **核心与宿主层（3）** | `mizar-core` · `mizar-client` · `mizar-tui` | 领域核与 `MizarRuntime::build` 静态组合根；零终端跨端宿主运行时；CLI / `mizar exec` / 终端入口 |

## 本地快速验证命令

修改 UI 相关纯逻辑可使用秒级单包检查；调整跨 crate 枚举、协议或装配顺序时务必运行完整 workspace 验证（CI 以 clippy zero-warning 与测试全绿为准）：

```bash title="常用开发与 CI 验证回路"
# 修改 UI 时的秒级快检
cargo check -p mizar-tui-ui

# 验证最小 feature 组合（关闭 codemode / mcp）不漏编译门控
cargo check --locked -p mizar-core --no-default-features --all-targets

# 其余 CI 检查
cargo fmt --all -- --check
cargo clippy --locked --workspace --all-targets -- -D warnings
cargo test --locked --workspace --no-fail-fast
```
