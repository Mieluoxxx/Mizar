Mizar 启动后会主动检测你当前终端的背景亮度与色彩支持能力（默认行为 `--theme auto`），也可以通过启动参数 `--theme <PRESET>`（见 [CLI 参数](/tui/cli/)）或在会话中输入 `/theme`（见 [斜杠命令](/tui/commands/)）即时预览并切换。

```bash title="指定预设主题启动"
# 显式使用暗底暖粉强调色主题
mizar --theme sakura-dark

# 跳过颜色探测握手，使用固定真彩暗色或极简 16 色主题
mizar --theme mist-dark
mizar --theme ansi16
```

## 自适应颜色探测机制

在默认的 `--theme auto` 模式下，Mizar 会按以下顺序判断终端明暗与配色方案：

1. 开机时主动通过终端查询协议探测前景/背景 RGB 与前 16 号调色板；
2. 若终端环境无法返回查询结果，则回退检查 `$COLORFGBG` 环境变量；
3. 在深色终端自动选用 `mist-dark`，在浅色终端自动切换为 `mist-light`。

## 6 套预设主题

运行 `/theme` 即可在 TUI 中实时对比并切换下面 6 套预设：

- **`auto`（默认）**：结合终端颜色探测与 `$COLORFGBG` 回退，在深色与浅色终端之间自动选用 `mist-dark` 或 `mist-light`。
- **`mist-dark`**：默认真彩暗色主题，以低刺激中性灰蓝为底、清晰高对比区分用户与模型角色。
- **`mist-light`**：面向白天强光或白底终端校准的真彩浅色主题，保留温和边框与易读代码块反差。
- **`sakura-dark`**：暗底暖粉强调色主题，灵感源自清晨绯樱点缀。
- **`system`**：尊重并映射你宿主终端本身配好的 16 个 ANSI 调色板色彩，如果你精心调校过终端配色方案，这一档最能与周围界面融为一体。
- **`ansi16`**：极简经典 16 色语义映射，面向老旧终端模拟器或通过基础 SSH / TTY 接入的环境，确保零偏色与稳定对比度。

<Callout type="tip">
  在无真实终端 TTY 的管道或部分极慢响应 SSH 链路中，如果想跳过颜色探测握手直接使用固定配色，显式传递 <code>--theme mist-dark</code> 或 <code>--theme ansi16</code> 即可瞬间完成初始化。
</Callout>
