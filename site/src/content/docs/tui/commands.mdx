在输入框起始位置敲 `/` 即开启命令补全。`@` 文件引用、长粘贴折叠与排队/插队发送见 [终端界面与双模视口](/tui/)；完整键盘热键对照见 [快捷键速查](/tui/keybinds/)；本地 Shell 执行请使用 [本地 Bash 模式](/tui/bash-mode/)。

## 模型与视图风格

| 命令 | 快捷键 | 作用 |
| :--- | :--- | :--- |
| `/settings` · `/config` | — | 打开交互式配置面板（界面/运行/压缩/模块热开关，即时生效并原子保存） |
| `/model` | <kbd>Ctrl</kbd>+<kbd>L</kbd> | 交互式切换已配置的提供方与模型 |
| `/effort` | <kbd>Tab</kbd> | 调整推理强度（`off` 到 `max`，空输入框按 Tab 循环） |
| `/thinking` | — | 打开/折叠模型思考链展示 |
| `/theme` | — | 实时预览并切换终端主题配色（6 套预设，详见 [终端主题](/tui/themes/)） |

## 会话、压缩与分叉控制

| 命令 | 说明 |
| :--- | :--- |
| `/compact [focus]` | 手动触发上下文检查点压缩（可附聚焦说明，支持按 `Esc` 取消，详见 [会话、分叉与性能轨迹](/tui/sessions/)） |
| `/tree` | 打开对话树视图，从任意历史回合分叉探索新思路（详见 [会话、分叉与性能轨迹](/tui/sessions/)） |
| `/clear` · `/new` | 清空当前视口并开启全新会话 |
| `/export` | 将当前会话导出为可读文本或记录 |
| `/exit` · `/quit` · `/q` | 退出 Mizar 并在终端打印可随时接续的 `--resume` 命令 |

## 视口、轨迹与诊断

| 命令 | 快捷键 | 作用 |
| :--- | :--- | :--- |
| `/trace` | <kbd>Ctrl</kbd>+<kbd>T</kbd> | 打开全屏三泳道轨迹分析器排查耗时热点（详见 [会话、分叉与性能轨迹](/tui/sessions/)） |
| `/panel` | <kbd>Ctrl</kbd>+<kbd>B</kbd> | 切换右侧状态面板（终端 ≥ 96 列时可用） |
| `/view` | <kbd>F3</kbd> | 无损切换 Fullscreen 全屏与 Inline 内联视口 |
| `/mouse` | <kbd>F2</kbd> | 放行或接管终端鼠标，便于原生划词复制 |
| `/stats` | — | 汇总打印当前会话 Token 与耗时统计 |

## 工具、规则与安全管理

| 命令 | 说明 |
| :--- | :--- |
| `/tools` | 列出当前生效的所有工具及其可见层级（参见 [内置工具](/tools/)） |
| `/mcp` | 检查全部 MCP 服务器连接态、工具数量与报错详情（参见 [MCP 服务器接入](/mcp/)） |
| `/skills` | 打开交互式技能选择器；带 `list` 参数（`/skills list`）直接输出清单（参见 [可复用技能](/skills/)） |
| `/instructions` | 诊断已注入的 `AGENTS.md` / `CLAUDE.md` 来源链、字节与淘汰状态（参见 [项目规则](/instructions/)） |
| `/approval` | 在会话中切换审批闸门（`/approval ask` 开启，`/approval off` 关闭；参见 [权限与安全](/security/)） |
| `/help` · `/h` | 在对话流内快速打印命令与热键帮助 |

<Callout type="tip">

在空输入框按 <kbd>?</kbd> 可随时呼出内置热键助记面板；完整按键分组表请查阅 [快捷键速查](/tui/keybinds/)。

</Callout>
