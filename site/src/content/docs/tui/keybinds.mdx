以下汇总 Mizar 终端界面中已内置的快捷键与输入触发前缀。`@` 引用、长粘贴折叠与排队/插队心法详见 [终端界面与双模视口](/tui/)；对应斜杠命令请参阅 [斜杠命令](/tui/commands/)。

## 发送与编辑器控制

| 快捷键 | 功能 |
| :--- | :--- |
| <kbd>Enter</kbd> | 发送当前输入；助手运行中时将新消息排入尾部等待队列（Follow-up） |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | 立即插队打断（Steer），中止当前流式输出或工具执行并转向新指示 |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> · <kbd>Alt</kbd>+<kbd>Enter</kbd> · <kbd>Ctrl</kbd>+<kbd>J</kbd> | 在一段提示词内手工换行继续输入 |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | 将自动折叠的长粘贴标签（`[paste #1 +42 lines]`）原地展开为明文编辑 |
| <kbd>Ctrl</kbd>+<kbd>G</kbd> | 唤起 `$VISUAL` 或 `$EDITOR` 外部编辑器撰写复杂提示词 |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | 模糊搜索历史发送过的提示词 |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> / <kbd>Ctrl</kbd>+<kbd>K</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | 按词回删 / 删除到行尾 / 粘贴已删除文本 |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 撤销最近一次输入框修改 |
| <kbd>Tab</kbd> | 有补全浮层时确认填充；空输入框时循环切换推理强度（`/effort`，`off` 到 `max`） |

## 视口、面板与模式切换

| 快捷键 | 功能 |
| :--- | :--- |
| <kbd>!</kbd> / <kbd>!!</kbd> | 在空输入框首字符键入以进入 [本地 Bash 模式](/tui/bash-mode/)（`!` 载入上下文，`!!` 仅本地运行） |
| <kbd>F3</kbd> | 无损切换 Fullscreen 全屏与 Inline 内联视口（对应 `/view`） |
| <kbd>F2</kbd> | 放行或接管终端鼠标，便于在 Fullscreen 下原生划词复制（对应 `/mouse`） |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | 展开或收起右侧分栏诊断面板（终端宽度 ≥ 96 列时可用，对应 `/panel`） |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | 打开全屏三泳道轨迹分析器排查耗时热点（对应 [`/trace`](/tui/sessions/)） |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | 打开交互式提供方与模型切换器（对应 `/model`） |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | 统一展开或收起消息流里的思考链与工具详情 |

## 对话浏览与退出

| 快捷键 | 功能 |
| :--- | :--- |
| <kbd>PageUp</kbd> / <kbd>PageDown</kbd> · <kbd>Ctrl</kbd>+<kbd>U</kbd> | 上下翻页浏览历史消息与长输出 |
| <kbd>Ctrl</kbd>+<kbd>Home</kbd> / <kbd>Ctrl</kbd>+<kbd>End</kbd> | 一键直达对话顶部或跳回最新消息 |
| <kbd>?</kbd> | 在空输入状态快速打开快捷键助记面板 |
| <kbd>Esc</kbd> | 关闭当前浮层、退出 Bash 模式，或在运行中中止任务/子进程组 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>D</kbd> | 清空输入或安全退出 Mizar |

<Callout type="tip">

Fullscreen 模式下除按 <kbd>F2</kbd> 外，macOS Terminal、iTerm2、Ghostty 与大多数终端还支持按住 <kbd>Option</kbd>（或 <kbd>Alt</kbd>）强行触发原生划词复制。进入 `/trace` 轨迹分析器后的视图内操作键见 [会话、分叉与性能轨迹](/tui/sessions/)。

</Callout>
