Mizar 由 `cordis` 微内核驱动，将全部能力拆分为 **33 个职责正交的 Virtual Workspace Crate**（**28 个运行时/插件 Crate + 5 个纯核心 Crate**，Rust `1.98.0`、Edition 2024），通过 `inject` / `provide` 服务容器与 5 种事件分发模式（`emit`、`parallel`、`serial`、`bail`、`waterfall`）装配为确定性 Agent 运行时。

## 33 个 Crate 分层拓扑

| 层级 | Crate 清单（数量） | 职责与核心约束 |
| :--- | :--- | :--- |
| **L1 宿主、跨端运行时与装配层**（3） | `mizar-tui`、`mizar-client`、`mizar-agent-spine` | 唯一可执行入口 `mizar`、跨端宿主运行时（**Merak 直嵌边界**：`mizar-client` 严禁引入 `ratatui` / `crossterm` / `mizar-tui-ui`），以及装配 12 个可选模块的 `"spinePlugins"` 控制器 |
| **L2 编排、观测与存储层**（4） | `mizar-agent-loop`、`mizar-trajectory`、`mizar-session-jsonl`、`mizar-session-title` | `"agentLoop"` 主循环、轨迹事件收集与 `RepeatToolGuard`、按 `cwd` 分桶惰性落盘与 SHA-256 Blob 外置的宽容 JSONL 持久化（零版本号拒绝）、后台异步标题总结 |
| **L3 工具、压缩与指令插件层**（9） | `mizar-tools-coding`、`mizar-tool-search`、`mizar-codemode`、`mizar-mcp`、`mizar-skills`、`mizar-tool-fs`、`mizar-tool-time`、`mizar-instructions`、`mizar-compaction` | 可按配置热启停的功能插件。其中 `mizar-instructions` 仅注入 `"systemPrompt"` 不注册工具；`mizar-skills` 不注册工具（仅按需注入 `<available_skills>` 与展开 `/<name>`） |
| **L4 核心基础服务与 LLM 协议栈**（4 + 7 = 11） | 核心服务：`mizar-llm`、`mizar-session`、`mizar-system-prompt`、`mizar-tools`；传输与协议：`mizar-llm-http`、`mizar-llm-retry`、`mizar-llm-router`、`mizar-llm-completions`、`mizar-llm-responses`、`mizar-llm-messages`、`mizar-llm-mock` | 抽象层零 HTTP 栈；所有 `reqwest` TLS/SSE 传输统一收口在 `mizar-llm-http`，四协议适配器均注入 `"llm"` |
| **L5 微内核底座**（1） | `cordis` | 上下文树 `Context`、`Fiber` 生命周期状态机、`ctx.effect` 倒序清理、服务注入与事件通道 |
| **纯核心孤岛**（5） | `mizar-client-core`、`mizar-tui-ui`、`mizar-trajectory-core`、`mizar-image`、`mizar-llm-types` | 零重型异步/IO 依赖（其中 `mizar-image` 负责 PNG/JPEG/WebP/GIF 魔数识别、EXIF 校正、100 MP 像素限制与 2048 px / 5 MB base64 压缩管线） |

<Callout type="danger" title="不可破坏的两道编译隔离红线">
  1. <strong>五大纯核心红线</strong>：<code>mizar-client-core</code>、<code>mizar-tui-ui</code>、<code>mizar-trajectory-core</code>、<code>mizar-image</code>、<code>mizar-llm-types</code> <strong>严禁引入</strong> <code>tokio</code>、<code>cordis</code>、<code>reqwest</code>、<code>rquickjs</code>、<code>rusqlite</code>。<br />
  2. <strong>跨端宿主红线（Merak Desktop）</strong>：<code>mizar-client</code> 与 <code>mizar-client-core</code> <strong>严禁引入</strong> <code>ratatui</code>、<code>crossterm</code> 或 <code>mizar-tui-ui</code>，保证核心宿主逻辑零终端渲染绑定。
</Callout>

## Cordis 插件与三段工具管线规则

```rust title="插件骨架示例（Cordis Service 依赖与副作用托管）"
impl Plugin for ExamplePlugin {
    type Config = ();
    fn name(&self) -> Option<&str> { Some("example-plugin") }   // kebab-case
    fn inject(&self) -> Inject { Inject::from(["tools"]) }       // camelCase 服务名

    fn apply(&self, ctx: Context, _cfg: ()) -> BoxFuture<'static, Result<Option<Cleanup>, BoxError>> {
        Box::pin(async move {
            let tools = ctx.tools()?;
            ctx.effect("example-register", move || {
                // 在容器挂载工具或钩子，返回反向清理闭包；Fiber 卸载时 LIFO 自动清理
                Ok(())
            })?;
            Ok(None)
        })
    }
}
```

- **全仓 10+1 服务名（始终使用 `<Name>ContextExt` 扩展方法读取）**：`llm`、`tools`、`sessions`、`systemPrompt`、`agentLoop`、`skills`、`mcp`、`trajectory`、`compaction`、`spinePlugins`（以及路由服务 `llmRouter`）。
- **漏写 `inject` 坑点**：若插件未在 `inject()` 声明所需服务却在 `apply()` 中调用读取，系统**不会 panic**，而是返回 `MissingInject` 并把该 Fiber 置入 `FAILED` 状态——导致工具静默消失，排查成本远高于 panic。
- **三段 Tool Waterfall 管线**：
  `tools/pre-execute`（挂载 `Compaction` 写前文件护栏与 `ApprovalGate` 审批闸门） → `tools/execute`（执行具体工具并通过 `with_file_mutation_queue` 对同路径写操作排队） → `tools/post-execute`（挂载 `RepeatToolGuard` 异常计数及结果记录）。

## Cargo Feature 裁剪与工程约定

- **`mizar-agent-spine` Features**：支持按 `legacy`、`coding`、`compaction`、`jsonl`、`session-title`、`trajectory`、`router` 组合裁剪。传入 `--no-default-features` 可验证仅加载纯净核心容器的最小编译通过性；所有可选模块导入必须配齐 `#[cfg(feature = "...")]`。
- **代码组织与文案语言**：禁止 `mod.rs`（统一 `foo.rs` + `foo/bar.rs`）；公共错误统一采用 `thiserror` 与 `cordis::BoxError`（不引入 `anyhow`）；`//!` 注释与运行时面向终端用户的报错用**中文**，而工具给模型看的 `description` 与参数说明**必须保持英文**。

## 验证策略与 CI 门禁

仓库**禁止编写任何测试代码**（不建 `tests/`，不写 `#[cfg(test)]`，不加 `[dev-dependencies]`）：结构、类型、feature 组合与 lint 由静态门禁兜底，行为验收全部通过真实终端 / 真实二进制的用户故事清单（`docs/stories.md`）黑盒实测。合入前务必跑通全部静态门禁（`clippy` 任何 warning 即失败）：

```sh title="工作区静态门禁验证命令" kind="terminal"
cargo check -p mizar-tui-ui                                              # 纯 UI 改动的毫秒级反馈回路
cargo check --workspace                                                  # 修改跨 crate 事件/结构体后必跑
cargo check --locked -p mizar-agent-spine --no-default-features --all-targets
cargo fmt --all -- --check
cargo clippy --locked --workspace --all-targets -- -D warnings
```
