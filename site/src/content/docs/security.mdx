Mizar 的权限控制由两条互不正交的防线构成：**路径作用范围限制（`restrictToWorkspace`）** 与 **非只读工具执行前的人工审批闸门（`--approve` / `/approval ask`）**。

<Callout type="warning" title="开箱默认全放行（本地效率优先）">
  为顺畅进行本地仓库开发，Mizar 默认设置为 <code>restrictToWorkspace: false</code> 且 <code>ApprovalMode::Auto</code>——即模型可以直接读写跨目录路径并免弹窗执行 <code>bash</code>。处理陌生仓库、运行不可信脚本或执行批量危险操作前，请务必至少开启一条防线。
</Callout>

## 轴一：工作区路径锁（`restrictToWorkspace`）

在 `settings.json` 中设置 `"restrictToWorkspace": true` 后，全部内置文件工具（`mizar-tools-coding` 的 `read`、`write`、`edit`、`grep`、`find` 以及 `mizar-tool-fs` 的 `read_file`、`list_dir`）的解析函数都会将目标路径严格钉死在当前工作区根目录之内：

- **符号链接防逃逸保护（`resolve_canonical_target`）**：不仅检查字面路径前缀，还会自顶向下逐段解析真实符号链接目标，即便针对尚不存在的新建文件路径，也会沿着最近的已有祖先目录完成规范化（`canonicalize`）再拼接剩余子路径验证是否在工作区边界内。同时内置 **40 跳符号链接循环深度防护**，防止恶意软链形成死循环或绕出仓库目录。
- **Shell 工具盲区警示**：`restrictToWorkspace` **仅对文件类内置工具生效，不会对 `bash` 启动的 OS 子进程注入 seccomp / sandbox-exec / chroot 隔离**。也就是说，如果同时允许模型调用 `bash`，模型仍可通过 `cat /etc/passwd` 或 `rm ../other-repo` 等命令越过工作区边界。

## 轴二：交互式审批闸门（`--approve` / `/approval ask`）

在终端宿主层中由 `mizar-client` 的 `ApprovalGatePlugin` 挂载在 `tools/pre-execute` 管线上：

- **触发方式**：启动传入 `--approve`、配置 `ui.approvalMode: "ask"`，或在工作台内随时运行 `/approval ask` 开启（`/approval auto` 切回免审）。
- **拦截对象**：放行只读工具（`read`、`grep`、`find`、`list_dir`、`get_time`、`recall`），拦截所有产生副作用或可变执行的非只读工具——包含 **`write`、`edit`、`bash`、`codemode` 以及外部非只读 MCP 工具**（注意：`codemode` 沙箱内部触发的嵌套写工具同样会过审批）。
- **四选交互决策**：
  1. **单次放行**：仅批准当前这次调用。
  2. **本工具始终放行**：将当前工具名加入本次会话免审白名单。
  3. **拒绝**：中断本次执行并返回拒绝错误。
  4. **附带理由拒绝**：中断本次执行并将你填写的约束文本直接回馈给模型，引导模型改写方案后再试。

<Callout type="note" title="用户手输入的 ! / !! 本地命令不经审批闸门">
  在工作台输入框以 <code>!</code> 或 <code>!!</code> 开头的本地 Bash 命令属于用户本人显式输入执行，直接绕过 <code>ApprovalGatePlugin</code>，也不受模型工具白名单制约。
</Callout>

## 推荐的纵深防御配置组合

| 使用场景 | 推荐命令 / 配置 | 防御效果 |
| :--- | :--- | :--- |
| **未知开源仓库人工审计** | `mizar --approve -C /path/to/untrusted` + `restrictToWorkspace: true` | 软链/文件锁在仓库内，且一切 `bash` / `write` / `edit` / `codemode` 必须人工点头确认 |
| **零写入只读 Code Review** | `mizar --read-only -C /path/to/repo` | 工具集直接裁剪为 `read` / `grep` / `find`（加 `recall`），无任何写工具与 `bash` |
| **禁用 Shell 但允许改代码** | `"restrictToWorkspace": true, "excludeTools": ["bash"]` | 保留文件与沙箱读写并由 40 跳软链护栏锁区，彻底消除 Shell 越界通道 |
| **高危 MCP 工具定向物理屏蔽** | `"excludeTools": ["mcp__prod__*", "*_drop_*"]` | 通配匹配即升为 `Hidden`，在声明列表与 `codemode` 沙箱中双端永久禁绝 |
| **干净的一次性沙盒试验** | `mizar --isolated --no-persist -C /tmp/sandbox` | 忽略 `~/.mizar` 与项目盘上配置且不向 `sessions.sqlite` 落盘痕迹 |
