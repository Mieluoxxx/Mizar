遇到异常时可先执行 `CORDIS_LOG=debug mizar exec "ping"` 查看结构化运行日志，或按下方症状表直接定位并修复。

## 1. 路由、凭据与 TLS 网络

| 症状 / 报错 | 常见原因 | 解决方案 |
| :--- | :--- | :--- |
| `no LLM provider or route configured` | 既无环境变量密钥，也无 `models.json` 且未指定 `--provider mock` | 导出 `API_KEY` + `BASE_URL` + `MODEL`，或用 `mizar --provider mock --model mock-v1` |
| `unknown provider "<name>"` | `--provider` 名称既不是四大内置提供方，也不在 `models.json` 中 | 检查 `models.json` 键名拼写，或配合 `--protocol` 与 `--base-url` 临时指定路由 |
| 企业内网 / HTTPS 代理报 TLS 证书验证失败 | 自签名根证书未注入 Rust `reqwest` 客户端信任链 | 导出 `SSL_CERT_FILE`、`CURL_CA_BUNDLE`、`REQUESTS_CA_BUNDLE` 或 `NODE_EXTRA_CA_CERTS` 指向企业 `.pem` 根证书 |
| 内网无外网时启动停顿等待检查更新 | 启动后台检查 GitHub Releases 超时（6s） | 设置 `export MIZAR_OFFLINE=1` 或 `export MIZAR_SKIP_VERSION_CHECK=1` |

## 2. 兼容网关 400 报错与截断异常

当通过 OneAPI、LiteLLM、vLLM、Ollama 等中转或私有端点调用时：

- **报错不支持 `developer` role**：在对应提供方 `compat` 中设 `"supportsDeveloperRole": false`。
- **报错 `stream_options` / `include_usage` 非法**：设 `"supportsUsageInStreaming": false`。
- **报错 `max_completion_tokens` 未识别**：设 `"maxTokensField": "max_tokens"`，若网关不识别 `max_output_tokens` 再设 `"supportsMaxOutputTokens": false`。
- **报错推理模型不支持 `temperature` / `reasoning_effort`**：按需将 `"supportsTemperature": false` 或 `"supportsReasoningEffort": false`。
- **`exec` 返回 `code=max_tokens`（退出码 `1`）**：单步回复撞到输出上限被硬截断；可通过 `--max-tokens` 或提高 `models.json` 中的 `maxTokens` 后重试。
- **频繁触发 `repeat-tool-guard`**：说明模型陷入同一参数的死循环，打开 `Ctrl+T` 切换到 Hotspots / Inspector 检查是校验错误还是文件未找到；也可核对网关是否正确回传工具调用结果。

## 3. JSONL 持久化、Blob 与搜索工具安装

- **启动或退出报持久化错误（`code=storage` / TUI 红字告警）**：检查 `~/.mizar/sessions` 目录权限或磁盘空间；可用 `MIZAR_SESSIONS_DIR=/tmp/mizar-sessions` 或 `settings.json` `sessionsDir` 切换可写目录，或在只读评测环境传入 `--no-persist` / `MIZAR_SESSIONS_DIR=memory`。
- **老会话恢复时提示部分图片 Blob 缺失**：`blobs/<sha256>` 文件被清理或损坏时，JSONL 读取器会自动剔除丢失的图片附件并记告警日志，文本历史与完好附件仍正常恢复。
- **老会话崩溃遗留未配对 `tool_call` 导致网关拒绝重放**：运行 `/tree` 分叉或 `-r <id>` 恢复时会自动执行孤儿调用自愈补全，重新恢复即可正常继续。
- **提示找不到 `rg` 或下载超时**：交互式 TUI 会自动下载并校验 `rg` / `fd`，也可运行 `mizar install-tools --force` 预装；无头 `exec` 模式仅查找本地已安装的 `rg` / `fd`。如直连 GitHub 较慢，默认会自动回退 `https://ghfast.top` 镜像，离线环境请设 `MIZAR_OFFLINE=1`。

## 4. MCP、`codemode` 与指令发现

- **默认只看到 4 个工具，或者 MCP 工具没直接出现在首轮声明中**：`MinimalCoding` 默认仅声明 `read` / `bash` / `edit` / `write`；外部 MCP 默认处于 `Codemode` 暴露等级（启用 `codemode` exposure 的 MCP 服务会在初始化时按需激活 `codemode` 沙箱，其余场景下 `codemode` 默认休眠）。可通过 `--tools codemode`、`toolsPreset: "all"` 或在 `mcp.json` 对高频工具设 `"exposure": "direct"` 调整，并用 `/mcp` 与 `/tools` 查看实时状态。
- **`codemode` 沙箱 120s 超时**：脚本内嵌套跑了耗时超过 2 分钟的测试或构建命令。长耗时任务应改调独立 `bash` 工具（上限 `600s`），或调大 `settings.json` 中 `codemode.timeoutMs`。如需彻底停用 `codemode`，将其写入 `disabledPlugins: ["codemode"]`。
- **修改了子目录 `AGENTS.md` 没立刻生效**：`mizar-instructions` 采用启动期静态发现与一次性注入以稳住 KV Cache，修改后开启新进程即可加载；用 `/instructions` 可确认实际注入的文件列表及是否触发 `maxBytes` 祖先淘汰。

## 5. 终端显示、剪贴板与划词复制

- **色彩失真或退化**：确认终端导出 `COLORTERM=truecolor`，或运行 `/theme ansi16` 切换 16 色主题；`[[Done]]` 胶囊缺图标时设 `MIZAR_TUI_PILL_ICONS=0`。
- **Fullscreen 模式下鼠标没法直接框选跨屏文字**：Fullscreen 开启了应用内鼠标拖拽，按 **`F2`**（或 `/mouse`）暂停鼠标捕捉即可直接划词，或者切换到 `--inline`（`/view inline`）接入终端原生滚动区。
- **JSON 解析启动红条警告**：Mizar 使用严格 JSON，删除 `settings.json` / `models.json` / `mcp.json` 中的 `//` 注释与多余尾逗号。
