Typing `/` at the beginning of the input box opens slash command completion. For `@` file mentions, long-paste folding, and queued vs. steering sends, see [Terminal UI & Dual-Mode Viewports](/en/tui/); for all keyboard shortcuts, see [Keybinds](/en/tui/keybinds/); for direct shell execution, see [Local Bash Mode](/en/tui/bash-mode/).

## Model & Display Style

| Command | Shortcut | Description |
| :--- | :--- | :--- |
| `/model` | <kbd>Ctrl</kbd>+<kbd>L</kbd> | Interactively switch between configured providers and models |
| `/effort` | <kbd>Tab</kbd> | Adjust reasoning effort (`off` through `max`; press `Tab` on an empty input to cycle) |
| `/thinking` | — | Expand or collapse model reasoning chain display |
| `/theme` | — | Live-preview and switch terminal color themes (6 presets; see [Terminal Themes](/en/tui/themes/)) |

## Session & Branching Control

| Command | Description |
| :--- | :--- |
| `/tree` | Open the conversation tree view to fork and explore a new approach from any prior turn (see [Sessions, Branching & Performance Traces](/en/tui/sessions/)) |
| `/clear` · `/new` | Clear the current viewport and start a brand-new session |
| `/export` | Export the current session as readable text or transcript records |
| `/exit` · `/quit` · `/q` | Exit Mizar and print a ready-to-run `--resume` command in the terminal |

## Viewport, Trace & Diagnostics

| Command | Shortcut | Description |
| :--- | :--- | :--- |
| `/trace` | <kbd>Ctrl</kbd>+<kbd>T</kbd> | Open the full-screen three-lane trajectory analyzer to pinpoint latency hotspots (see [Sessions, Branching & Performance Traces](/en/tui/sessions/)) |
| `/panel` | <kbd>Ctrl</kbd>+<kbd>B</kbd> | Toggle the right-hand status panel (available when terminal width ≥ 96 columns) |
| `/view` | <kbd>F3</kbd> | Losslessly switch between Fullscreen and Inline viewports |
| `/mouse` | <kbd>F2</kbd> | Release or recapture terminal mouse events for native drag-select copying |
| `/stats` | — | Print a summary of current session token and timing statistics |

## Tools, Rules & Security

| Command | Description |
| :--- | :--- |
| `/tools` | List all currently active tools and their exposure levels (see [Built-in Tools](/en/tools/)) |
| `/mcp` | Inspect connection status, tool counts, and error details for all MCP servers (see [MCP Server Integration](/en/mcp/)) |
| `/skills` | Open the interactive skill picker; pass `list` (`/skills list`) to print the list directly (see [Reusable Skills](/en/skills/)) |
| `/instructions` | Diagnose the source chain, byte counts, and eviction status of injected `AGENTS.md` / `CLAUDE.md` files (see [Project Rules](/en/instructions/)) |
| `/approval` | Toggle the approval gate mid-session (`/approval ask` to enable, `/approval off` to disable; see [Permissions & Security](/en/security/)) |
| `/help` · `/h` | Quickly print command and hotkey help inside the chat stream |

<Callout type="tip">

Press <kbd>?</kbd> from an empty input box anytime to pop up the built-in shortcut cheat sheet, or browse the grouped tables in [Keybinds](/en/tui/keybinds/).

</Callout>
