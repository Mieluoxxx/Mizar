On startup, Mizar actively probes your terminal's background luminance and color support (defaulting to `--theme auto`). You can also override it via `--theme <PRESET>` (see [CLI Flags](/en/tui/cli/)) or run `/theme` (see [Commands](/en/tui/commands/)) at runtime to preview and switch themes live.

```bash title="Launch with an explicit theme preset"
# Explicitly select the dark warm-pink accent theme
mizar --theme sakura-dark

# Skip the color-probe handshake with a fixed truecolor dark or 16-color theme
mizar --theme mist-dark
mizar --theme ansi16
```

## Adaptive Color Detection

Under the default `--theme auto` behavior, Mizar determines terminal brightness and palette capabilities in three steps:

1. At startup, queries foreground/background RGB values and the first 16 palette slots using terminal query protocols;
2. If the terminal does not respond to probes, falls back to checking the `$COLORFGBG` environment variable;
3. Automatically chooses `mist-dark` on dark terminals and `mist-light` on light terminals.

## All 6 Preset Themes

Run `/theme` inside the TUI to compare and switch among all 6 presets in real time:

- **`auto` (default)**: Combines terminal color probing with `$COLORFGBG` fallback to select `mist-dark` or `mist-light` automatically based on your terminal background.
- **`mist-dark`**: Default truecolor dark theme with low-fatigue neutral slate-blue surfaces and crisp contrast distinguishing user and model roles.
- **`mist-light`**: Truecolor light theme calibrated for bright daylight or light-background terminals, retaining gentle borders and legible code block contrast.
- **`sakura-dark`**: Dark background with warm pink accents, inspired by early-morning cherry blossoms.
- **`system`**: Respects and maps the 16 ANSI palette colors already configured in your host terminal—ideal if you have finely tuned your own terminal color scheme and want seamless integration.
- **`ansi16`**: Minimal classic 16-color semantic mapping built for legacy terminal emulators or basic SSH / TTY sessions, guaranteeing zero color cast and reliable contrast.

<Callout type="tip">
  In piped environments without a real TTY or over very high-latency SSH links, pass <code>--theme mist-dark</code> or <code>--theme ansi16</code> explicitly to skip the color-probe handshake and initialize instantaneously.
</Callout>
