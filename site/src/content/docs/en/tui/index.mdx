Mizar is built around two viewport modes for high-intensity terminal coding that can be hot-swapped at any time: **Fullscreen mode** and **Inline mode**. Without exiting or restarting, you can press <kbd>F3</kbd> (or run `/view`) mid-session to switch instantaneously while keeping all messages, queued tasks, and panel states intact.

```bash title="Launch with an initial viewport mode"
# Default: Fullscreen workbench
mizar

# Inline viewport (keeps terminal history scrollable above)
mizar --inline
```

## When to Use Fullscreen vs. Inline

- **Fullscreen (default, alternate screen buffer)**: Ideal for immersive large-scale refactors, code reviews, and monitoring multiple tasks with the side panel open. Long outputs, the branching tree selector ([`/tree`](/en/tui/sessions/)), and the three-lane trajectory analyzer ([`/trace`](/en/tui/sessions/)) all get full-screen real estate.
- **Inline (inline viewport, preserves primary terminal scrollback)**: Ideal if you prefer alternating between host shell commands and AI questions in the same terminal tab. Inline collapses input and recent turns into a compact **7–14 line** viewport at the bottom of your terminal (adapting to terminal height), letting you compare recent command logs above with AI diagnostics below at a glance.

## Split Diagnostics Panel (<kbd>Ctrl</kbd>+<kbd>B</kbd>)

When your terminal window reaches **96 columns or more**, pressing <kbd>Ctrl</kbd>+<kbd>B</kbd> (or running `/panel`) toggles the live diagnostics sidebar on the right, containing four switchable tabs (navigate via arrow keys or mouse click):

1. **Context**: Visually breaks down token share across the system prompt, project rules (`AGENTS.md`), conversation turns, and tool definitions.
2. **Files**: Lists every file path read, created, or edited during the current session.
3. **Tools**: Tracks cumulative tool call counts, recent statuses, and any long-running tasks still in flight.
4. **Stats**: Displays session input/output token usage, latency pacing, and local command counts.

## Idle Launchpad & Quick Start

When you start a blank session, an interactive set of shortcuts (**Launchpad**) renders above the input box. Click an entry or use its shortcut to jump straight into common actions:

- Search and `@`-mention workspace files
- Inspect the currently active tool list (`/tools`, see [Built-in Tools](/en/tools/))
- Check which `AGENTS.md` files are loaded and inspect remaining budget (`/instructions`, see [Project Rules (AGENTS.md)](/en/instructions/))
- Jump straight into the `!` local command sandbox (see [Local Bash Mode](/en/tui/bash-mode/))

## Native Mouse Selection Passthrough (<kbd>F2</kbd>)

In Fullscreen mode, Mizar enables mouse capture by default so you can scroll long conversations with the wheel or click sidebar tabs and trajectory regions; the trade-off is that dragging to select text scrolls the view instead.

When you need to drag-select and copy a multi-line error block:

- Press <kbd>F2</kbd> once (or run `/mouse`) to temporarily hand mouse control back to the host terminal, allowing normal left-click drag selection and copying;
- Press <kbd>F2</kbd> again when done to immediately restore wheel scrolling and click interactions.

<Callout type="tip">
  macOS Terminal, iTerm2, Ghostty, and most terminal emulators also support holding <kbd>Option</kbd> (or <kbd>Alt</kbd>) to force native text selection without even pressing <code>F2</code>.
</Callout>

## Precise `@` File & Line-Range Mentions

Feeding context effectively doesn't require manually pasting whole files. Typing `@` anywhere in the input box opens an autocomplete popup listing the `.gitignore`-filtered workspace tree; meanwhile, email addresses like `dev@company.com` won't falsely trigger completion (it requires `@` to appear at the start of a line or after whitespace, brackets, or CJK punctuation).

```text title="Common @ mention syntax"
# Reference a specific line range to save whole-file tokens
@src/config.rs#L18-45 Are the boundary conditions in this merge function right?

# Drill down directories step by step: select a directory and keep typing to enter subdirectories
@crates/mizar-tools/

# Wrap paths containing spaces in double quotes
@"docs/release notes/v1.md" Please double-check this checklist
```

Built-in safeguard limits prevent accidentally dumping build artifacts or huge log files into the conversation:

- Single files exceeding **50,000 characters** are automatically truncated, and total expanded mentions in a single message are capped at **200,000 characters**;
- Directory expansion lists at most **200 entries**, and files larger than **16 MiB** or binary files are automatically skipped with a notice.

## Automatic Long-Paste Folding & <kbd>Ctrl</kbd>+<kbd>E</kbd> Expand

When you paste a large stack trace or log snippet from a terminal or logging system (over **8 lines** or **600 characters**), Mizar avoids blowing up the editor into hundreds of lines where you lose your cursor, collapsing it instead into a tidy placeholder badge:

```text title="Folded paste example"
Please help me diagnose the root cause of this error:
[paste #1 +42 lines]
```

When you send the message, Mizar automatically restores the full original content for the model; if you want to trim trailing noise before sending, press <kbd>Ctrl</kbd>+<kbd>E</kbd> to expand it inline into editable plain text.

## Queue Follow-up vs. Immediate Steer

While the assistant is streaming output or chaining tool calls, you don't have to sit idle waiting for it to finish before typing your next instruction—keep typing in the input box and choose between two send modes to control the cadence:

- **<kbd>Enter</kbd> (Queue Follow-up)**: While a task is still running, pressing `Enter` appends your new message to the trailing queue. Once Mizar finishes the current turn cleanly and delivers its response, it immediately picks up your queued task next.
- **<kbd>Ctrl</kbd>+<kbd>Enter</kbd> (Immediate Steer)**: If you spot the model heading in the wrong direction (for example, editing the wrong file), type your correction and press `Ctrl+Enter` to interrupt the current stream or tool execution immediately and pivot on the spot to your new instruction.

<Callout type="tip">

To insert a manual newline while writing a multi-line prompt, use <kbd>Shift</kbd>+<kbd>Enter</kbd>, <kbd>Alt</kbd>+<kbd>Enter</kbd>, or <kbd>Ctrl</kbd>+<kbd>J</kbd>. See [Commands](/en/tui/commands/) and [Keybinds](/en/tui/keybinds/) for the full command and shortcut references.

</Callout>
