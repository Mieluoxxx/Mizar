Mizar's terminal workbench pairs the pure UI state machine `mizar-tui-ui` with the cross-end host runtime `mizar-client`. It opens in a full-screen dual-pane workspace by default and can hot-swap into an inline mode that flushes completed turns back to native terminal scrollback.

## Dual Viewports & Side Panel

- **Fullscreen (default)**: Owns the alternate screen with virtualized Markdown, word-level diffs, a 2-column `TimelineRail` (appears when width `>= 60` cols and `>= 2` turns; click nodes to jump), and the `Ctrl+B` split side panel.
- **4-State Circular Tool Lights & Strict 1-Line Collapsed Cards**: Each tool call shows a 4-state circular indicator: muted hollow `○` while arguments stream (`Drafting`), solid yellow `●` while executing (`Running`), solid green `●` on success (`Done`), and solid red `●` on failure or denial (`Error`/`Blocked`). Collapsed cards always render strictly as **1 single header line** with zero preview lines; press `Ctrl+O` to inspect full arguments, diffs, and outputs. Unfinished drafts transition to red on truncation or `Esc` cancellation.
- **Background `rg` / `fd` Installer**: Interactive TUI concurrently ensures `rg` and `fd` under `~/.mizar/bin` (with `ghfast.top` mirror fallback on slow/stalled transfers), sharing the single-flight install with `grep`; you can also pre-install via `mizar install-tools`.
- **Inline (`--inline` / `/view inline`)**: Keeps a compact 7–14 row composer at the bottom while flushing finished turns to native terminal scrollback (`Cmd+F`, native scrollbar, and drag selection work naturally with `mouse_capture=false`).
- **Right Side Panel (`Ctrl+B` / `/panel`)**: Shown when terminal width `>= 96` cols (default 42 cols, min 30, draggable divider) with `Ctx` (context bar + TTFT/TPS), `File`, `Tool`, and `Stat` tabs.
- **Native Selection Escape (`F2` / `/mouse`)**: Temporarily pauses in-app mouse capture in Fullscreen so your terminal emulator handles text selection directly.

## Input Ergonomics & Local Bash (`!` / `!!`)

- **`@` Fuzzy File Mentions**: Typing `@` triggers background `.gitignore`-aware suggestions from `WorkspaceFileCache`; submitted mentions are expanded by `FileMentionsPlugin` as `ContextNotice` items before the step runs.
- **Multiline & Busy Queueing**: `Shift+Enter`, `Alt+Enter`, or `Ctrl+J` inserts newlines; submitting while streaming pushes follow-ups into `PromptQueue`.
- **Clipboard Images (`Ctrl+V`)**: Pastes text or sniffs/normalizes clipboard images via `mizar-client` for vision-capable models.
- **Local Bash Prefixes**:
  - `! <command>`: Runs locally **and feeds stdout/stderr into the next model turn** (ideal after fixing tests).
  - `!! <command>`: Runs locally at **zero token cost** — skipped automatically by `derive_messages()`.

## Themes & `pi-emphasis` Visual Grammar

- **6 Built-in Themes**: `auto` (adapts to terminal `COLORFGBG` dark/light detection), `mist-dark`, `mist-light`, `sakura-dark`, `system`, and `ansi16`. Ensure `COLORTERM=truecolor` in non-TTY test harnesses to enable 24-bit color.
- **`pi-emphasis` Grammar**: Interactive TUI renders markers like `[[Done]]`, `[[Failed]]`, and `[[Needs you]]` as semantic status pills while preserving clean raw Markdown in JSONL storage, clipboard copy, and `/export`. Disable individual layers via environment variables:
  - `MIZAR_TUI_EMPHASIS=0`: Disable emphasis rendering globally
  - `MIZAR_TUI_ROUND_CAPS=0` (or `PI_EMPHASIS_ROUND_CAPS=0`): Disable rounded pill borders
  - `MIZAR_TUI_PILL_ICONS=0` (or `PI_EMPHASIS_PILL_ICONS=0`): Hide Nerd Font pill icons
  - `MIZAR_TUI_EMPHASIS_GUIDANCE=0` (or `PI_EMPHASIS_GUIDANCE=0`): Do not append emphasis reply guidance to system prompt
  - `MIZAR_TUI_PROGRAM_STATUS=0`: Disable terminal title/progress reporting
