Mizar is a terminal-native AI coding workbench built for heavy command-line workflows. It offers a dual-mode viewport—switching between a full-screen dashboard and an Inline mode that preserves terminal scrollback—along with built-in local shell execution, hierarchical project rule discovery, MCP server integration, and a lightweight JS orchestration sandbox.

Whether you want to explore the interface first or connect DeepSeek, OpenAI, or Anthropic and start editing code right away, one command gets you up and running.

## What to Do in Your First Minute

Once inside the workbench, you don't need to memorize every [shortcut](/en/tui/keybinds/) at once—start with these three high-impact actions:

<Steps>
  <li>
    <p><strong>Feed exact source files to the model with <code>@</code></strong>: Typing <code>@</code> in the input box opens a <code>.gitignore</code>-aware file completion menu. You can even write <code>@src/main.rs#L1-40 What edge cases does this argument parser have?</code> to skip manual copy-pasting.</p>
  </li>
  <li>
    <p><strong>Run terminal commands directly with <code>!</code> and <code>!!</code></strong>: Commands starting with <code>!!git status</code> are purely local quick checks—they never enter conversation context and cost zero tokens. Switch to a single bang like <code>!cargo test</code>, and command output or errors become context for the next turn so the AI can fix them for you.</p>
  </li>
  <li>
    <p><strong>Control views with <a href="/en/tui/commands/">slash commands</a> and <a href="/en/tui/keybinds/">hotkeys</a></strong>: Press <kbd>Ctrl</kbd>+<kbd>B</kbd> to toggle the right-hand status panel showing current context usage and active files; press <kbd>F3</kbd> to switch seamlessly between Fullscreen focus mode and Inline scrollback mode; run <code>/model</code> or <code>/effort</code> anytime to adjust the model and reasoning effort.</p>
  </li>
</Steps>
