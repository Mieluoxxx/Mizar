Mizar is a Rust terminal AI coding agent built on the **33-crate Cordis microkernel** (`mizar` binary). It pairs a streaming inference loop (`stream → tools → append-only session persistence`) with strict KV-cache prefix stability, offering both an interactive dual-viewport TUI workbench and a deterministic headless `exec` runner.

<Callout type="info" title="Architecture Alignment">
  This handbook documents the **33-crate Cordis microkernel branch**: always-on QuickJS `codemode`, a single static `recall` tool, a 4-section static English system prompt, startup-static `AGENTS.md` loading, cache-aware tail pruning, Compaction B-5 guards, and `--trace-out` structured trajectory export.
</Callout>

## Installation

Mizar builds on pinned Rust `1.98.0` (Edition 2024). Install the prebuilt single binary, build from source, or self-update cleanly:

<CodeTabs
  tabs={[
    {
      label: 'Prebuilt Binary',
      lang: 'sh',
      code: `curl -fsSL https://raw.githubusercontent.com/Mieluoxxx/Mizar/main/scripts/install.sh | sh
mizar --version`,
    },
    {
      label: 'From Source',
      lang: 'sh',
      code: `git clone https://github.com/Mieluoxxx/Mizar.git
cd Mizar
cargo install --locked --path crates/mizar-tui`,
    },
    {
      label: 'Self-Update',
      lang: 'sh',
      code: `mizar update --check      # Check latest release only
mizar update              # Upgrade to latest stable release
mizar update -v 0.1.6 -f  # Force-install a specific tag`,
    },
  ]}
/>

In air-gapped environments, set `MIZAR_OFFLINE=1` or `MIZAR_SKIP_VERSION_CHECK=1` to skip startup version checks, or point `MIZAR_RELEASE_BASE_URL` at an internal mirror.

## Three-Minute Quick Start

<Steps>
  <li>
    <strong>Choose credentials or offline mock</strong>: Use <code>--provider mock</code> without any API key to verify tool loops locally, or export a provider key / configure <code>~/.mizar/models.json</code>.
  </li>
  <li>
    <strong>Launch interactive or headless mode</strong>: Run <code>mizar</code> to open the terminal workbench, or pass <code>exec</code> / <code>-p</code> for single-turn automation.
  </li>
  <li>
    <strong>Inspect edits and telemetry</strong>: Press <code>Ctrl+T</code> interactively to open the <code>/trace</code> 3-lane profiler, or pass <code>--trace-out trace.json</code> in headless mode to export <code>TrajectoryExport</code>.
  </li>
</Steps>

<CodeTabs
  tabs={[
    {
      label: 'Keyless Offline Demo',
      lang: 'sh',
      code: `mizar --provider mock --model mock-v1`,
    },
    {
      label: 'DeepSeek / OpenAI',
      lang: 'sh',
      code: `export DEEPSEEK_API_KEY="sk-..."
mizar -C /path/to/repo`,
    },
    {

      lang: 'sh',
      code: `export PROTOCOL=responses
export BASE_URL="https://api.example.com/v1"
export API_KEY="sk-..."
export MODEL="gpt-5"
mizar exec "Explain workspace layout in Cargo.toml"`,
    },
  ]}
/>

## Execution Modes

| Entrypoint | Use Case | Interaction | Persistence |
| :--- | :--- | :--- | :--- |
| `mizar [OPTIONS]` | Daily coding, multi-turn refactors, reviews | Fullscreen / Inline viewports, `!` / `!!` local Bash, `--approve` prompts | Persists to `~/.mizar/sessions.sqlite` by default (`--no-persist` disables) |
| `mizar exec [OPTIONS] [<prompt>]` | CI pipelines, eval harnesses, batch scripts | Headless single-turn run; prints text or JSON summary to `stdout` | Supports `--isolated`, `--timeout`, `--trace-out`, and explicit exit codes |

<Callout type="tip" title="Strict Route Errors When Unconfigured">
  If no credentials exist in environment variables or <code>~/.mizar/models.json</code> and you do not pass <code>--provider mock</code>, Mizar fails immediately with <code>NoRouteConfigured</code> instead of issuing unauthenticated network requests.
</Callout>
