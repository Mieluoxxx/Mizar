## 宽容 JSONL 持久化与 Blob 外置

- **按 `cwd` 分桶与惰性落盘（`mizar-session-jsonl`）**：默认落盘于 `~/.mizar/sessions`（可通过 `MIZAR_SESSIONS_DIR` 或 `settings.json` 中的 `sessionsDir` 覆写；设为 `none` / `off` / `memory` 或 CLI `--no-persist` 则退化为纯内存会话）。按规范化（`canonicalize`）后的 `cwd` 归入 `<sessions_dir>/<encoded-cwd>/<YYYYMMDDTHHMMSSZ>_<session_id>.jsonl`（无 `cwd` 归入 `_global`，symlink 指向同一真实路径归入同一桶）。采用**惰性落盘**：空会话不会在磁盘生成空 `.jsonl` 文件，直到首次追加非空事件或执行 `fork` 才原子建文件，TUI 空会话退出也不输出无效的 `--resume` 命令。
- **宽容格式与零版本号拒绝**：记录类型含 `session`、`entry` 与 `header-patch`。读取器按字节逐行扫描，自动剥离 BOM 与空行、安全跳过崩溃导致的半截尾行或未知 `record` / 未知 `event`（同时追踪 `max_persisted_seq`，确保续写 `seq` 严格递增且续写前自动补齐 `\n`），且**不以版本号拒开（容忍 `0` 与更高整数 `formatVersion`）**。
- **内容寻址图片外置（`blobs/<sha256>`）**：用户、上下文与工具结果中的 base64 图片在落盘前经纯 Rust RFC 6234 SHA-256 计算摘要，原子写入同级 `blobs/<sha256>` 并改以 `"blob:sha256:<hex>"` 引用；恢复时若个别 blob 缺失，仅剔除对应丢失附件并记告警日志，不中断会话载入。
- **单写者隔离与非静默错误上报**：启动期执行目录可写探针；独立 `mizar-jsonl-writer` 后台线程通过 `mpsc` 顺序追加与 `flush` / `flush_async` 同步屏障保障有序落盘，并暴露 `last_error()`。初始化、运行期或退出 `flush` 失败时，TUI 立即显式弹出 `NoticeLevel::Error` / 闪烁提示并在退出报错，`mizar exec` 则以 `reason="storage"`、退出码 `1` 失败退出（绝不静默丢数据）。
- **恢复与防丢挂起修复**：使用 `-c` / `--continue` 自动续接当前工作区最近会话，或 `-r` / `--resume [id]` 指定历史会话。若上次进程异常崩溃导致最后一条 `tool_call` 缺少对应的 `tool_result`，恢复重放与 `/tree` 分叉都会自动补齐自愈占位记录，防止严格校验协议报错。

## `/tree` 树形分叉与自动标题

- **`/tree` 分叉**：在任意历史序列点 `seq` 执行 `fork(id, up_to_seq)`，会按前缀事件新建关联 `parent_id` 与 `fork_seq` 的子会话。`SessionStore::fork` 与 JSONL `exec_fork` 均拒绝与已有会话 ID 冲突或覆盖磁盘既有文件，保证原始主线与已有分支丝毫无损。
- **后台标题生成（`mizar-session-title`）**：首轮用户输入及每间隔 `20` 轮会异步总结 `MMDD｜TYPE｜Topic` 格式标题（如 `FIX`、`FEA`、`DOC`）；一旦通过 `/rename <title>` 手动命名（标记 `TitleSource::Manual`），后台自动更新会尊重人工标题不再覆盖；无参执行 `/rename` 则立即触发模型重生成。

## 上下文压缩（Compaction B-5）与热缓存感知剪枝

当长对话逼近模型上下文窗口上限时，Mizar 通过**两道渐进机制**保住准确率与 Prompt / KV Cache 命中率：

1. **热缓存感知尾部剪枝（`mizar-compaction/src/pruning.rs`）**：
   - **`compaction.supersedeReads`（默认 `true`）**：当同一文件路径随后已被完整重新 `read` 覆盖时，裁掉早先的旧 `read` 返回文本（及重读图片附件，同步缩减上下文预算估算）。
   - **`compaction.dropUseless`（默认 `true`）**：清理已被后续操作覆盖或确认无效的零命中检索噪声输出（始终保护 `SKILL.md` 读取结果不被裁）。
   - **热缓存与 8k 热尾保护**：对于启用缓存的 OpenAI Responses、具备推理能力的 Anthropic Messages，或历史中仍包含 Responses 回放 / 签名 `thinking` 块的会话，常规步前处于**热缓存保护期**，不改写旧回执；其余会话也会保留最近 **`8,000` Token 热尾**不动（仅闲置超过 `90` 分钟冷缓存后清仓）。通过向事件流追加轻量 `SessionEvent::ToolResultPrune` 标记实现，既有历史永不原地修改。
2. **检查点摘要压缩（`mizar-compaction` B-5 体系）**：
   - **窗口计算优先级**：`--context-window` > `MIZAR_CONTEXT_WINDOW` > 模型目录 `contextWindow` > `compaction.defaultContextWindow` > `128,000`；可由 `compaction.maxContextTokens` 设软上限。
   - **触发与护栏**：当估算用量跨过 `effective_window * triggerRatio`（默认 `0.80`，保留最近 `keepRecentTokens = 20000` Token 原文）时，热缓存会话先尝试全量剪枝回收有净收益的旧回执，重估仍超阈值才请求 LLM 摘要（或通过 `/compact [focus]` 手动触发）。
   - **B-5 精确校准与溢出刷新**：锚定上轮真实 `TokenUsage::prompt_tokens()` 校准余量；摘要强置 `ReasoningEffort::Off`；空包装或截断摘要不入检查点并触发折半转录兜底；触发 L3 窗口溢出或隐性连续截断时以实际净缩减恢复，**并按 `session_id` 同步刷新系统提示词与声明工具表**；挂载在 `tools/pre-execute` 的 **`FileGuardTracker`** 会拦截对已压缩文件的盲目整文件 `write` 覆写。

## `/trace` 剖析器与 `--trace-out` 结构化导出

- **交互三泳道剖析器（`Ctrl+T` / `/trace`）**：
  - 顶部 **WaveBand** 全会话脉冲带支持点击跳转到任意轮次。
  - **Timeline** 页签分三道并行展示：**L0 输入与告警**（用户输入、`CTX`、`RepeatToolGuard` 连续重复调用告警）、**L1 模型响应**（TTFT 等待 + 流式 Decode 段）、**L2 工具执行**（包括 `codemode` 内部的嵌套子工具跨度与单工具实际耗时）。支持在 `Duration` / `Seq` / `Actual` 三种时间轴间切换。
  - **Hotspots** 与 **Inspector** 展示各工具耗时排行、单步 Token 详情及完整入参/返回。
- **无头结构化导出（`--trace-out <path>` / `MIZAR_TRACE_OUT`）**：`mizar exec` 运行结束时无论成功、超时或异常退出，都会按命令行优先于环境变量的规则将完整的 `TrajectoryExport` JSON 原子写入目标路径（并行工具批次中 `tool_result.duration_ms` 与 `result.tool_ms` 精确统计单工具各自真实执行耗时）；交互模式也可用 `/export [path]` 导出原始 JSONL 轨迹。
